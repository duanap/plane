# Plane V1 AI + Deploy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish Plane V1 with three non-cheating AI difficulties, a playable AI browser mode, repeatable Docker deployment, and CI verification.

**Architecture:** Add a pure AI decision module that consumes only public attack observations, then a small human-vs-AI session wrapper that applies decisions through the existing game engine. Add a separate AI browser entry without changing online-room rules. Package the existing zero-dependency runtime with a multi-stage Dockerfile and verify the entire repository in GitHub Actions.

**Tech Stack:** Node.js 22+, TypeScript 5.8+, built-in `node:test`, native browser ES modules, Docker, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-11-v1-ai-deploy-design.md`

## Global Constraints

- AI decision functions must never accept or inspect the human fleet.
- Board size remains exactly 10 x 10 with exactly 3 aircraft per player.
- Existing `src/game/*` remains the rule authority.
- Existing local and online modes must remain functional.
- Runtime remains zero third-party dependencies.
- Deployment must expose `PORT` with default 4173 and retain `/health`.
