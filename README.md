# Plane · 炸飞机

一个 10×10 坐标推理对战小游戏。双方各部署 3 架固定形状飞机，轮流攻击坐标；命中机头即击落整架飞机，率先击落全部 3 架者获胜。

## 当前版本

V1 第一里程碑已经包含：

- 10×10 棋盘与固定 10 格飞机几何规则
- 上 / 右 / 下 / 左四向旋转
- 出界、重叠校验（允许相邻）
- 3 架飞机随机合法布局
- MISS / HIT / DESTROYED 攻击判定
- 击中机头立即击落并公开整架飞机
- 重复攻击保护且不消耗回合
- 三架全灭胜负判定
- 本地双人 Hot-seat 可玩原型
- 玩家交接隐私屏，避免看到对方布阵
- 手机 / 桌面响应式棋盘

## 本地运行

要求 Node.js 22+ 与 TypeScript 5.8+。

```bash
npm test
npm run build
npm start
```

打开：

```text
http://localhost:4173
```

健康检查：

```text
GET /health
```
